BEPBuddy (Web)

BEPBuddy is a concept project intended to assist Blind Vendors in the B.E.P. Program. This web version of the application allows users to track invoices, create and submit monthly stand reports with attached invoices for ease. The project is constantly building and, with input and feedback from users, it can be a one-stop tool for all Blind Vendors & Consultants.
